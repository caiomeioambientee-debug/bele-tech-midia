# bele-tech-midia

Imagens dos posts do Instagram @bele.tech26, já aprovados.

A API do Instagram só publica carrossel com imagens em link público. Por isso, o fluxo
"Publicar carrossel" do n8n sobe aqui os 4 cards de cada post logo antes de publicar,
em `posts/pN-<execução>/card-1.jpg` … `card-4.jpg`.

Não guarde neste repositório nada que não possa ser público.
